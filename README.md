# Percent Bot (농심 신라면 20개입 최저가 탐색 봇)

네이버 쇼핑에서 실시간으로 '농심 신라면 봉지 20개입' 상품을 검색 및 필터링하여 최저가를 탐색하고, 목표 가격(15,000원) 이하 발생 시 카카오톡 '나에게 보내기'로 알림을 전송하는 봇입니다.

## 주요 기능
- **실시간 네이버 쇼핑 수집**: 광고(AD) 제거 및 순수 신라면 20개입 상품 정밀 필터링
- **가격/배송비 합산 비교**: 최저가 순위 산출 (1~3위 정보 요약 출력)
- **카카오톡 나에게 보내기 알림**: 목표가 달성 시 쇼핑몰 정보, 가격, 바로가기 링크 알림 전송 및 토큰 자동 갱신
- **외부 라이브러리 의존성 제로**: Python 표준 라이브러리(`urllib`, `json`, `re` 등)만으로 구동

## 실행 방법
```bash
python percent_bot.py
```

## 환경 설정 (.env)
카카오톡 알림을 사용하려면 프로젝트 루트에 `.env` 파일을 생성하고 아래 항목을 설정해야 합니다:
```env
KAKAO_REST_API_KEY=your_rest_api_key
KAKAO_CLIENT_SECRET=your_client_secret
KAKAO_REFRESH_TOKEN=your_refresh_token
```
*(주의: `.env` 파일은 민감한 인증 정보를 포함하므로 Git에 커밋되지 않습니다)*
